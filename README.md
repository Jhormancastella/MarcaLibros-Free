## Qué puedes hacer

- Crear marcalibros de una cara (**5 × 15 cm**) o doble cara (**10 × 15 cm**).
- Cargar imágenes desde tu equipo o desde una URL y ajustar el recorte.
- Activar o desactivar una perforación superior de 5 mm.
- Descargar el diseño en PDF, PNG o JPG.
- Usar el editor en computador, tablet o celular.

## Cómo usarlo

1. Elige el diseño de una cara o doble cara.
2. Carga la imagen y ajusta el recorte.
3. Presiona **Generar** y descarga tu marcalibros.

En el diseño de doble cara, recorta por la línea central para obtener dos piezas con bordes redondeados y únelas.

Para imprimir, utiliza papel opalina o fotográfico de **180 a 250 g/m²** y escala del 100 %.

| Tecnología | Uso en el proyecto |
|---|---|
| **HTML, CSS y JavaScript** | Interfaz, estilos adaptables e interacción del editor. |
| **Canvas API** | Composición de las caras, perforación y exportación de imágenes. |
| **Cropper.js** | Recorte y ajuste de las imágenes. |
| **jsPDF** | Generación de archivos PDF listos para imprimir. |
| **Web App Manifest y Service Worker** | Recursos de la aplicación y funcionamiento básico sin conexión. |
| **Bootstrap Icons** | Iconos de la interfaz. |
| **Cloudinary** | Subida opcional de diseños cuando el usuario la solicita. |

## Privacidad

Las imágenes se procesan en el navegador. Solo se envían a Cloudinary si eliges la opción de subirlas.
